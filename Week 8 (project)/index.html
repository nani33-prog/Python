03 · The language of logic

Boolean algebra

Boolean algebra is ordinary algebra for bits. It gives us a compact way to describe and simplify logic.

Three handy starting points

IdentityA · 1 = A   A + 0 = A
DominationA · 0 = 0   A + 1 = 1
ComplementA · ¬A = 0   A + ¬A = 1
Double NOT¬(¬A) = A
CommutativeA · B = B · A
DistributiveA · (B + C) = A·B + A·C

Reading the symbols

Variables like A and B stand for bits. A bar or ¬ means NOT, a dot means AND, and a plus means OR.

¬A   = NOT A
A · B = A AND B
A + B = A OR B
A ⊕ B = A XOR B

Use the laws to make an expression simpler, which can mean fewer gates and a smaller circuit.

04 · Put gates together

A simple circuit

Imagine a room light controlled from two doors. Flipping either switch changes the light. XOR captures that behavior.

If both switches match (0,0 or 1,1), the output is 0. If they differ, the output is 1. In a real hallway circuit, either switch can toggle the light.

05 · Logic with a memory

When circuits remember

So far, outputs depended only on the inputs right now. Sequential circuits also use stored information from the past.

01 / COMBINATIONAL

No memory

Output depends only on current inputs. Adders and the gate circuits above are examples.

02 / FLIP-FLOPS

One stored bit

A flip-flop is a tiny memory element. It can hold a 0 or 1, often updating on a clock tick.

03 / SEQUENTIAL

Bits over time

Connect flip-flops to build registers and counters. Larger collections of stored bits form memory.

Keep in mindCombinational logic computes what happens now. Sequential logic uses what happened before, too.
